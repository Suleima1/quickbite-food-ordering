# QuickBite — Food Ordering Website

QuickBite is a responsive front-end food ordering website built as a student project.

## Features
- Responsive layout for phones, tablets, and computers
- Food menu with categories: Meals, Burgers, Drinks, and Sides
- Add food to cart
- Increase or decrease quantities and remove items
- Automatic cart count and subtotal calculation in Nigerian naira
- Demo checkout form with basic required-field validation
- No payment is collected and no customer details are sent or stored

## Technologies
- HTML5
- CSS3
- JavaScript (vanilla)

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Browse the menu and test the cart and demo checkout.

No installation or database is required.

## Deploy online
### GitHub Pages
1. Create a public repository on GitHub, for example `quickbite-food-ordering`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. Your live link will be shown in the Pages section.

## Project limitations
This is a front-end demonstration. It does not have a real backend, user accounts, database, order dashboard, delivery integration, or online payment system. Do not use it to collect real customer information.
